## 🌟 Overview & Key Capabilities

The BhukkadVerse mobile application connects foodies, neighborhood kitchens, and delivery partners under an egalitarian 4-way economic model:

1. **🍢 Customer Storefront:**
   - 3 Curated Culinary Tiers: **Iconic Street Food Legends**, **Heritage Luxury Fine Dining**, and **Neighborhood Cloud Kitchens**.
   - Hyperlocal Discovery with live Haversine distance and serviceability check.
   - Single-vendor cart enforcement with transparent bill breakdown: Flat ₹5 platform fee, 100% free delivery over ₹99, and transparent 5% GST (zero bill shock).
   - Live Order Tracking with real-time ETA and status stepper.

2. **🍳 Vendor Order-Accept Hub:**
   - Real-time incoming orders queue with pending badge counters and haptic feedback.
   - Kitchen workflow lifecycle: `CONFIRMED` -> `PREPARING` -> `OUT_FOR_DELIVERY`.
   - Dynamic Menu & Stock controls: Instant toggle for In Stock vs Sold Out dishes.
   - 90% Vendor Net Payout ledger with automated T+1 direct bank settlement info.

3. **🛵 Rider Fleet & Cash Float Ledger:**
   - Active delivery tasks with customer and kitchen contacts.
   - Anti-theft COD Virtual Float Locking: Visual progress gauge tracking cash in hand against the ₹1,500 maximum limit.
   - Wage Accounting: Guaranteed ₹35 wage credited per completed delivery.
   - Cash Deposit / UPI reconciliation workflow to reset float.
   - Live GPS Telemetry broadcaster streaming coordinates to dispatch.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- Expo Go app on your physical iOS/Android phone, OR Android Studio emulator / iOS simulator.

### Run Local Development
```bash
# Navigate to mobile directory
cd mobile

# Start the Expo Metro Bundler
npm start

# Or directly target Android / iOS / Web
npm run android
npm run ios
npm run web
```
