# Getting Support for Bhukkad Verse

Welcome to the **Bhukkad Verse** community! We are glad you're here. Here are the best ways to get help, find answers, and connect with other contributors.

---

## 📖 1. Check the Documentation

Before opening an issue or asking for support, check our available documentation:
- **[README.md](README.md)**: Project overview, features, and quickstart guide.
- **[CONTRIBUTING.md](CONTRIBUTING.md)**: Guide on setting up the backend and frontend locally, and submitting pull requests.
- **[docs/ Directory](docs/README.md)**:
  - [PROJECT_REPORT.md](docs/PROJECT_REPORT.md): Complete system architecture, ER diagrams, financial split models, and API endpoints.
  - [FOODHUB_ARCHITECTURE_PLAN.md](docs/FOODHUB_ARCHITECTURE_PLAN.md): Multi-vendor food platform design specification.
  - [PRODUCTION_READINESS_AUDIT.md](docs/PRODUCTION_READINESS_AUDIT.md): Production checklists and security considerations.

---

## 💬 2. Community & Questions

- **GitHub Discussions / Issues**:
  - If you have a question about how something works, configuration questions, or ideas to discuss, feel free to open a Discussion or a Question issue using the provided templates.
  - Search existing issues and discussions first to see if your question has already been answered.

---

## 🐛 3. Reporting Bugs or Feature Requests

- **Bug Reports**: If you find an issue with the code or documentation, please submit a bug report via our [Issue Templates](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature Requests**: If you have an idea or improvement, submit a feature request via the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml).

---

## 🔒 4. Security Disclosures

For security vulnerabilities, please refer to [SECURITY.md](SECURITY.md) to report issues privately rather than using public channels.
