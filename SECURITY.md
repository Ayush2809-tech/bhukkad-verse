# Security Policy

The Bhukkad Verse team takes the security of our application, our users' data, and our vendors' privacy very seriously. We appreciate the responsible disclosure of security issues.

---

## Supported Versions

We currently support the latest version on the `main` branch:

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| < 1.0.0          | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Bhukkad Verse, please do **NOT** disclose it publicly via GitHub Issues, Discussions, or social media.

Instead, please report the vulnerability privately by following these steps:

1. **Email or Private Advisory**: 
   - Open a private security advisory through GitHub via **Security > Advisories > Report a vulnerability**.
   - Alternatively, contact the maintainers directly via repository owner profiles.

2. **Include in your report**:
   - A clear description of the vulnerability and affected component (frontend, backend API, authentication, database).
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - Potential impact of the issue (e.g., privilege escalation, unauthorized vendor access, data exposure).
   - Any suggested remediation or patches if available.

---

## What to Expect

- **Acknowledgment**: We will acknowledge receipt of your report within 48 to 72 hours.
- **Assessment**: We will investigate and assess the vulnerability's severity and impact.
- **Resolution**: Once verified, we will work on a fix in a private branch, draft a release, and credit you for responsible disclosure in the release notes (unless you request anonymity).

---

## Safe Harbor

We consider security research conducted under this policy to be authorized, and we will not pursue legal action against researchers who:
- Make a good faith effort to avoid privacy violations, destruction of data, and service interruption.
- Give us reasonable time to remediate the vulnerability before public disclosure.
- Do not exploit vulnerabilities beyond the minimum necessary to verify existence.

Thank you for helping keep Bhukkad Verse secure!
